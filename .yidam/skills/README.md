# skills

Domain-specific skills available to agents in this repository. Generic skills inherited
from yidam live in [`.yidam/.vendor/prelude/skills/`](../.vendor/prelude/skills/); skills that require
knowledge of this domain's corpus or toolkit live here.

Four are expected in this domain. Each reads corpus nodes and answers a question the graph
gate cannot — a well-formed node and a resolving edge say nothing about whether a
succession has a hole in it or whether two figures describe the same ground.

- **succession-audit** — reads an `office` and its `tenure` nodes; reports gaps and
  overlaps in the line of holders
- **boundary-comparability** — reads a `measure`, the `place` it describes, the annexation
  record and any erection `event` nodes between two dates; reports whether two figures
  describe the same ground
- **jurisdiction-at** — given a `place` and a date, returns every `jurisdiction` and
  `division` that covered it then
- **watershed-trace** — follows `flows-into` from any `natural-feature` to its outlet and
  lists the `place` nodes traversed

Add skills when a repeatable procedure emerges from inquiry — not preemptively.
